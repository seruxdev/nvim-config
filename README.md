# nvim-config

## Atajos de Neovim

| Atajo           | Acción                       | Descripción                                   |
|-----------------|------------------------------|-----------------------------------------------|
| Ctrl + w + H    | Mover foco a la ventana izquierda  | Cambia el foco al split de la izquierda      |
| Ctrl + w + J    | Mover foco a la ventana inferior  | Cambia el foco al split de abajo             |
| Ctrl + w + K    | Mover foco a la ventana superior  | Cambia el foco al split de arriba            |
| Ctrl + w + L    | Mover foco a la ventana derecha   | Cambia el foco al split de la derecha        |
| Ctrl + v        | Split vertical               | Divide la ventana actual verticalmente       |
| Ctrl + s        | Split horizontal             | Divide la ventana actual horizontalmente     |
| Ctrl + q        | Cerrar ventana               | Cierra la ventana actual                      |
| Ctrl + o        | Cerrar otras ventanas        | Cierra todas las ventanas excepto la actual  |

## Atajos de Neo-tree

| Atajo | Acción                       | Descripción                                   |
|-------|------------------------------|-----------------------------------------------|
| Alt + 1 | Abrir/cerrar Neo-tree       | Muestra u oculta el explorador lateral       |
| .       | Mostrar/ocultar archivos ocultos | Alterna archivos y carpetas ocultas         |
| a       | Crear nuevo archivo         | Crea un archivo dentro de la carpeta actual  |
| A       | Crear nuevo directorio      | Crea un directorio dentro de la carpeta actual |
| r       | Renombrar archivo/directorio | Cambia el nombre del archivo o carpeta seleccionada |
| d       | Eliminar archivo            | Borra el archivo o carpeta seleccionada      |

## Atajos de Comentarios y Autocompletado

| Atajo        | Acción               | Descripción                                   |
|--------------|--------------------|-----------------------------------------------|
| Ctrl + g + c | Comentar selección  | Comenta el bloque de código seleccionado     |
| Ctrl + n     | Siguiente sugerencia | Mueve hacia abajo en la lista de autocompletado de `cmp` |
| Ctrl + p     | Sugerencia anterior  | Mueve hacia arriba en la lista de autocompletado de `cmp` |
| Blink        | Autocompletado       | Indica que se muestra una sugerencia de autocompletado (`cmp`) |
